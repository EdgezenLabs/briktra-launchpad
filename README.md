# Briktra Launchpad

Web shell around the Briktra Flutter web build.

**Docs policy — read this before adding any documentation, human or AI agent:** this repo has
at most three documentation files, total: this `README.md` (setup/run), `CURRENT.md` (known
issues, gotchas, current state — create it if it doesn't exist yet), and `PRODUCT.md`
(features/product description — same). **Do not create any other documentation file** — no
audit notes, design docs, migration guides, or dated snapshots as separate files. Fold new
content into whichever of the three it belongs in instead.

```bash
npm i
npm run dev
```

Requires Node 20+.
